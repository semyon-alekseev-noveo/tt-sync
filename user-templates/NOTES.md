User's Obsidian templates (2026-10-14):
- Task note: frontmatter id (YYYYMMDDHHmm), created, task "[[title]]", project (link, optional), status (backlog...), priority, deadline, meta (meta category link), tags [task, work]. Sections: Goal and Context (desc), Subtasks (checkboxes), Review of done work, Links ([[Dash.tasks.base]], [[log-<id>]]), callout Metadata Source::.
- Note: frontmatter id, created, status (backlog/draft/working/done), type (Note/Idea/How-to/Reference/Practice/Problem), topic, project, meta, tags type/<x>, topic/<x>.
- MOC: frontmatter id, status, kind system, type Note, areas [[Area]] (Digital, Family, Growth, Health, Leisure, Mind, Money, Social, Work), topic, meta, tags system/moc (+system/project for project MOC). Active Zone has inline checkbox tasks.
- Log note: log-<taskId>.md, parent "[[task]]", parent_id, tags log; dated entries.
Tasks may or may not belong to a project; user can work without projects using meta category.
